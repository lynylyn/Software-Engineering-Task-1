# Software-Engineering-Task-1
-m pip install -r requirements.txt

Log in to last.fm and create an API key.

Copy apikey.sample.ini to apikey.ini and add your API key and secret.

This system allows you to find information on songs, artists, tags, and find currently trending music, using the last.fm API for that data. You can choose any of these options from the menu, accessed through the Python terminal. If you need to request help at any time, you're able to do that through one of the menu options.
